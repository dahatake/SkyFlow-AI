# デモスクリプト: 「エプロン上空の雷雨」

再現可能な開始URL: `http://localhost:5173/?clock=2027-01-11T08:00:00%2B08:00&demo=1`（ガイド付きデモのオーバーレイが各ステップを案内します）。デプロイ済みサイトの場合は、そのURLを使用してください。ネットワーク障害時のフォールバック: アプリはブラウザ内だけで動作し、エージェントはルールベースのアドバイザーにフォールバックします。バックアップ録画: `npm run build:deck` でデッキのPDFをエクスポートし、この手順の画面録画を保管しておきます。

## 10分版（実証を追加）

1. Overview: ライブフィード、2D/3D、フィルター（1分）。
2. ロールレンズをRamp Leadに切り替えてから元に戻し、各ロールに固有の優先事項が表示されることを示す（1分）。
3. Agentタブ: **エージェントトレース**（Detect、Triage、Resolver、Comms）と、各ステップが呼び出したツールを開く（2分）。
4. ModeをRule-based advisorに切り替えて再実行する: 同じオプションが得られ、決定論的なフォールバックを示す（1分）。
5. タスクリスト: 承認された意思決定によって作成された5W2Hタスク（1分）。
6. シミュレーター: パラメーターを変更し、Baseline / Scenario / Differenceを示す（1分）。
7. Optimize: ワンクリックのオプティマイザー（推奨のみ）（1分）。
8. Valueタブと次のステップの依頼で締めくくる（1分）。

| シナリオ | 回避した違反 | 回避したリスク | 回避したブロックタスク | イベントあたりの削減額（SGD） |
|---|---|---|---|---|
| 天候による遅延 | 0 | 3 | 28 | 1,680 |
| フライト遅延 | 1 | 3 | 10 | 3,100 |
| グランドスタッフ不在 | 0 | 9 | 60 | 3,600 |

これらの数値は `valueReport` から得られ、`app/tests/value.test.ts` で固定されています。数値が異なる場合は、シード、クロック、または前提条件が変更されています。

## 問題が発生した場合

- 空白ページまたはエラーバナー: Diagnosticsタブで Reset。
- エージェントサービスが遅い: ModeをRule-based advisorに設定。
- ネットワークなし: Teamsへの配信を除くすべてがオフラインで動作します。
