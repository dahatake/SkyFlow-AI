# ソースドキュメントの Markdown 変換版

親フォルダー内の .docx/.pptx ファイルから `markitdown` で生成したもので、AI ツールが読み取りや差分比較を行えるようにしています。オーサリングの元データは引き続きバイナリファイルです。編集後は `markitdown <file> -o <out>.md` で再生成してください。


注意: `SATS Project SPEAR - Solution Envisioning Output - AI Operations Control Tower.pptx` は、このリポジトリでは有効な OOXML zip ではなく (変換時に BadZipFile で失敗します)、Markdown 変換版がありません。PowerPoint から再エクスポートしたうえで、変換を再実行してください。
