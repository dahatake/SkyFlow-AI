Current demo · horizontal component architecture

One machine. No cloud or LLM.

All application logic runs in the browser. Localhost serves bundled assets only.

1 · React UI

Linked 2D / 3D views, dashboards, GPS replay and role lenses.

2 · Coded rules

Detect → Triage → Resolve → Comms. Engine-valid options, no model calls.

3 · Pure engine

Deterministic simulation, scoring, planning, optimization and value.

4 · Human approval

A manager approves derived overlays and owned 5W2H tasks. Baseline unchanged.

5 · Local storage

IndexedDB for decisions and audit; localStorage for preferences.

Bundled customer and seed data · No backend, Azure, Fabric, Teams delivery or external telemetry. Production concepts on other slides are future options only.

Resource and task optimiser

One click. Every reason shown.

  • Deterministic, priority-ordered heuristic with a rolling horizon and frozen window.
  • Hard limits: stand buffers, closures, weather, GSE travel distance, crew seats per stand.
  • Weights for SLA, distance, time and resources; presets for Balanced, SLA first, Resource saving and Time critical.
  • Explainable: before/after measures, every change with its reason, unresolved items left for a person.
  • Non-destructive: audit entry per run; baseline untouched (OPT-001 to OPT-004).
Production path: an exact or metaheuristic solver (MIP / CP-SAT) on Azure, behind the same interface.

Non-functional requirements

Every quality target has an answer.

NFR-001 · Performance

Normalised store, memoised selectors, viewport and layer simplification, 3D level of detail. Fabric Well-Architected in production.

NFR-002 · Accessibility

Keyboard paths, visible focus, icon plus text status, reduced-motion camera, Fluent design.

NFR-003 · Responsive

Control-room, laptop/tablet and compact ramp layouts; Teams cards for ramp leads.

NFR-004 · Explainability

Every derived value tagged Baseline or Simulated, with parameters, rule ID and cause.

NFR-005 · Safety boundary

Static hosting, no mutation endpoint, frozen baseline; write-back only in phase 2.

NFR-006 · Observability

Payload-free, exportable client diagnostics; Eventhouse metrics and logs in production.

Security · Identity

Microsoft Entra ID, row-level security by BU and airline, Purview lineage.

Check before phase 2 · Residency

Fabric data agent answers used in Copilot Studio may leave the Fabric boundary or region. Validate against the Singapore decision.

Seven reasons it de-risks delivery.

1

Fabric unifies Eventstreams, Eventhouse, Activator, Data Factory, OneLake, semantic models and BI: one capacity, one security model.

2

Real-time to action

Activator → Power Automate → Teams Adaptive Cards. Configuration, not middleware.

3

AI on the same foundation

Copilot Studio and Fabric data agents, Azure AI Foundry and Azure ML, IoT Hub and Azure Maps all read one OneLake model.

4

Security by design

Entra ID SSO and conditional access, RLS by BU and airline, Purview lineage, labels and DLP, Singapore region.

5

Open and portable

Delta / Parquet in OneLake, KQL, standard connectors, React/TypeScript, Bicep, azd and GitHub Actions. SATS owns the code.

6

Builds on the estate

Power BI skills and Microsoft 365 / Teams already in place; embeds in DSM. Less new infrastructure to run.

7

Delivery assurance

Innovation Hub architects, CSAM, Data and AI specialists, certified partners, and explicit exit criteria per horizon.
